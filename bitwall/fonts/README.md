# Fonts `letters` draws as pictures

Outline fonts for headings, drawn by Pillow into a kitty picture laid over
the cells the text takes (`letters.WHITE_RABBIT`, `BYTES256`, `VT323`).

| File | Font | Designer | Licence | From |
|---|---|---|---|---|
| `WhiteRabbit.ttf` | White Rabbit | Matthew Welch, 1999 | MIT, `WhiteRabbit-LICENSE.txt` | squaregear.net/fonts/whitrabt.zip |
| `256Bytes.otf` | Two Fifty Six Bytes | Ray Larabie, 2024 | CC0, no rights reserved (in the font) | 1001fonts.com/256-bytes-font.html |
| `VT323-Regular.ttf` | VT323, the DEC VT320's type | Peter Hull, 2011 | SIL OFL 1.1, `VT323-OFL.txt` | github.com/google/fonts, ofl/vt323 |
